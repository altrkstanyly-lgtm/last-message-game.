دليل رفع لعبة «آخر رسالة» إلى GitHub Pages
============================================

المستودع: https://github.com/altrkstanyly-lgtm/last-message-game

أولًا: افتح مجلد الرفع
----------------------
1. افتح مستكشف الملفات في Windows.
2. اذهب إلى مجلد GitHub-Upload الذي أعطاك Codex مساره.
3. تأكد أن index.html ومجلدات assets وscripts وstyles ظاهرة مباشرة داخل المجلد.

ثانيًا: ارفع الملفات
-------------------
1. افتح رابط المستودع أعلاه وسجّل الدخول بنفسك إذا طلب GitHub ذلك. لا تشارك كلمة المرور أو رمز التحقق.
2. اضغط Add file ثم Upload files.
3. ارجع إلى مجلد GitHub-Upload. اضغط في مساحة فارغة داخله ثم Ctrl+A لتحديد كل الملفات والمجلدات.
4. اسحب التحديد إلى مساحة الرفع في صفحة GitHub. اترك العناصر حتى تنتهي مؤشرات/رسائل الرفع؛ لا تغلق الصفحة مبكرًا.
5. تأكد من ظهور index.html ومجلدات assets وscripts وstyles في قائمة التغييرات، ثم اضغط Commit changes واحفظها في الفرع main.

ثالثًا: فعّل GitHub Pages
------------------------
1. من صفحة المستودع افتح Settings.
2. من القائمة اختر Pages.
3. تحت Build and deployment اختر Deploy from a branch.
4. اختر الفرع main والمجلد /(root)، ثم اضغط Save.
5. انتظر حتى ينتهي النشر وتظهر رسالة النجاح أو زر Visit site في صفحة Pages. قد يستغرق ظهور الموقع بضع دقائق.

رابعًا: افتح اللعبة واختبرها
---------------------------
الرابط المتوقع:
https://altrkstanyly-lgtm.github.io/last-message-game/

افتح الرابط أعلاه. إن لم يعمل بعد الحفظ مباشرة، انتظر قليلًا ثم حدّث الصفحة.
للتأكد من الموارد، جرّب هذه الروابط أيضًا:
https://altrkstanyly-lgtm.github.io/last-message-game/assets/backgrounds/home-night.svg
https://altrkstanyly-lgtm.github.io/last-message-game/manifest.webmanifest
https://altrkstanyly-lgtm.github.io/last-message-game/service-worker.js
ينبغي ألا تظهر صفحة 404.

ابدأ لعبة جديدة، واختبر الرسائل وسجل الحوار ودفتر الأدلة، ثم جرّب الحفظ بإعادة تحميل الصفحة والمتابعة في المتصفح نفسه. أكمل اللعب للتحقق من النهايتين. افتح الرابط كذلك في Safari على iPhone وفي Chrome على Android، وجرّب العرض الرأسي والأفقي والأزرار باللمس.

معلومات الوصول والخصوصية
------------------------
رابط GitHub Pages عام ويمكن مشاركته. ملفات اللعبة المنشورة ومحتوى المستودع العام متاحة للآخرين. لا يوجد حاليًا تحقق من شراء Gumroad ولا حماية تمنع مشاركة الرابط. اللعبة تحفظ التقدم محليًا في بيانات المتصفح؛ لا تزامن الحفظ بين الأجهزة أو المتصفحات.

هذه الحزمة لا تُرفع تلقائيًا. أنت من يختار الملفات ويرفعها من حسابك. لا تضع بيانات شخصية أو كلمات مرور أو رموز تحقق في المستودع.
